# Website display fonts

These fonts are self-hosted and licensed under the SIL Open Font License 1.1.
Their licenses are retained alongside the font files.

- `onest.ttf`: Onest variable font, reused from the Rebyu website's licensed
  asset. Original source: [Google Fonts Onest](https://github.com/google/fonts/tree/main/ofl/onest).
- `manrope.ttf`: Manrope variable font, sourced from
  [Google Fonts Manrope](https://github.com/google/fonts/tree/main/ofl/manrope).

Inter remains the documentation body face; Geist Mono remains the code face.
