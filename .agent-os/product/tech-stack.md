# Technical Stack

## Core Library

- **Primary Framework:** SolidJS (latest)
- **Language:** TypeScript 5.x
- **Build Tool:** tsup with ESBuild
- **Package Manager:** Bun
- **Module Format:** ESM

## Dependencies

- **State Management Core:** solid-js/store
- **Async Operations:** RxJS 7.x
- **Functional Utilities:** Remeda
- **Pattern Matching:** ts-pattern
- **ID Generation:** Custom nanoid implementation

## Development Tools

- **Testing Framework:** Bun test runner
- **Code Quality:** Biome (formatting and linting)
- **Git Hooks:** Lefthook
- **Version Control:** Git with conventional commits
- **CI/CD:** GitHub Actions
- **Dead Code Analysis:** Knip
- **Build:** Knope

## Development Experience

- **Type System:** Full TypeScript with advanced generics
- **Documentation:** TypeScript types as documentation
- **Examples:** Comprehensive test suite as usage examples

## Publishing

- **NPM Registry:** Public npm package
- **Package Name:** @carere/solux
- **License:** MIT
- **Versioning:** Semantic versioning
- **Distribution:** ESM

## Architecture Patterns

- **Programming Paradigm:** Functional programming (no classes)
- **Type Safety:** Type-first design with inference
- **Code Organization:** Single-responsibility modules
